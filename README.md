# Week 5: Array and Object Manipulation Drills

## About the Project
This project is part of my Advanced Frontend Web Development course. I used a food delivery dataset called Kigali Eats to practice JavaScript arrays and objects.

## What I Practiced
- Using `map()`, `filter()` and `find()`
- Calculating totals using `reduce()`
- Grouping and sorting data
- Updating objects without changing the original data
- Working with array methods and spread syntax

## Technologies Used
- JavaScript
- Node.js

## How to Run
1. Open the project folder in the terminal.
2. Run the following command:

   `node drills.js`

## Project Files
- `data.js` – Contains the orders dataset.
- `drills.js` – Contains the solutions to the workshop questions.
- `README.md` – Describes the project.
